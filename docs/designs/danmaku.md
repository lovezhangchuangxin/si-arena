# 弹幕对决

## 核心玩法

弹幕对决是独立的 1v1 游戏 `danmaku`：两架机体在由 seed 抽取的对称出生点上以惯性全向机动，每 tick 提交一个加速度输入并可朝 16 个方向发射快慢两档弹幕。弹幕飞过战场、出界即消失，命中判定为 1 格切比雪夫半径。每架机体 100 点生命，先被打到 0 点的一方落败；回合耗尽时生命多者胜。

匹配、排位、练习与 Boss 规则与其他 1v1 游戏相同，见[排位与匹配](ranked.md)：本游戏没有竞技场，玩家主动发起匹配，系统从其他上传了兼容代码的普通用户中选对手，没有对手时与官方 bot 练习。

## 战场与开局

| 项目 | 规则 |
| --- | --- |
| 人数 | 固定 2 人 |
| 战场 | 固定 32 × 24（宽 32，高 24） |
| 布局 | 由 seed 从 `DANMAKU_LAYOUTS` 均匀抽取：每项含一对中心对称的出生点 |
| 公平性 | 每个布局的出生点都关于战场中心 (31/2, 23/2) 中心对称，席位 0/1 各占一个对称出生点 |
| 时长 | 最多 600 tick |
| 初始生命 | 每架 100 点 |
| 视野 | 完整战场 |

坐标左上为 `(0, 0)`，向右 x 增大、向下 y 增大，全部为整数格。随机数使用 xorshift32，状态 `rngState` 随世界保存；**只有初始化消耗随机数（抽取布局，先空转两轮再用乘法散列压缩，避免相邻小种子输出线性相关），`step` 不再读取随机数**，对局完全由双方动作决定。

## 动作

每 tick 每架机体提交一个动作：

- `{ type: "idle" }`：放弃行动。
- `{ type: "act", move, fire, speed }`：
  - `move` 是 8 个加速度方向 `E NE N NW W SW S SE` 之一、`hold`（刹车）或 `null`（维持漂移）；
  - `fire` 是 16 个弹幕方向 `E ENE NE NNE N NNW NW WNW W WSW SW SSW S SSE SE ESE` 之一或 `null`；
  - `speed` 是 `"slow"` 或 `"fast"`（动作解析缺省归一化为 `"slow"`）。移动与开火同一 tick 同时生效。

## 结算顺序

1. **同时移动（惯性）**：`v = clamp(v + accel, ±1)`，然后按新速度逐格位移（先 x 轴后 y 轴）。撞到出界格的那一步停住、该轴速度分量回退，并发一次 `blocked` 事件。允许双方进入同一格（含互换）。
2. **同时开火**：在机体当前位置生成弹幕（记录速度档）；己方在飞弹幕已达 3 发时本 tick 开火无效（无事件）。席位 0 先于席位 1 分配 `serial`。
3. **弹幕飞行**：慢弹沿 `DANMAKU_SHOT_DELTAS` 基准位移表走 2 格（切比雪夫距离 2），快弹走两倍 4 格（切比雪夫距离 4）；两档弹速都严过机体满速的 1 格。路径按比例逐格推进（每轴 `floor(位移 × k / 格数)`，恒为整点），**每一格**都参与命中采样：与某架非发射者机体的切比雪夫距离 ≤ 1 即命中：扣 1 点生命、弹幕消失、发 `hit` 事件。路径出界的弹幕直接消失，无事件。弹幕不会命中发射者本人，弹幕之间互不影响、不对消；同一 tick 多发命中全部结伤。
4. **终局判定**：任一方生命 ≤ 0 或 `tick` 达到 600 时比赛结束。

## 观察与信息

观察包含完整战场：双方机体（位置、速度、生命）、全部在飞弹幕（位置、方向、速度档、所有者）与上一 tick 的公开事件。两个玩家的观察来自同一世界状态，只有 `selfId`/`selfSlot` 不同；不存在战争迷雾。

## 结果与排位

`reason` 为 `elimination`（一方生命归零）或 `tick-limit`（打满 600 tick）。`score` 是最终生命数：存活者与打满时限时生命多者排第 1；同 tick 双双归零、或时限内生命相同则并列第 1。排位结算沿用通用 1v1 Elo 流程。

## 官方 bot

官方 bot 采用「先躲后打」策略：为 9 个移动输入打分（模拟各输入下一 tick 的落点，惩罚将进入弹幕采样格与墙角的输入，保持 8 格上下交战距离并避开对手的格线），瞄准时按对手速度按弹丸飞行时间前置预测其位置、沿 16 向格线（快慢两档步长分别扫描）选误差最小的方向与速度档。它走普通选手的执行与限额路径，与它的比赛不计排位。

## 限额

沿用平台默认资源限额（每 tick CPU 与内存见发行 manifest），官方 bot 与普通玩家同路径执行。

## 深度设计意图

防止策略过早收敛的三个来源：seed 出生点让「背一个开局」失效、必须泛化；快慢弹配速与 3 发弹槽构成没有解析解的节奏决策；惯性移动叠加「弹速严过机体」让走位精度与变向节奏成为可长期打磨的机械深度。全部机制保持整数运算与完全确定性，性能需求维持在低位。
