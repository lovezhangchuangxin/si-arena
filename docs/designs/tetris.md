# 俄罗斯方块

## 核心玩法

俄罗斯方块是独立的单人游戏 `tetris`：一局只有你和 10 × 20 的场地。7-bag 随机发牌、消行得分、每 10 行提速；新块放不下（top-out）或打满 1500 tick 时结束，本局得分为最终成绩。排行榜按历史最高分排名，同一玩家可以随时重开刷新纪录。

本游戏没有对手、练习或 Boss 概念：玩家主动发起即开局，每次挑战独立成局，结束即结算 `bestScore`。无需等待或选择对手；任务仍进入 worker 队列，资源繁忙时会等待。同一用户同一游戏最多一个未完成的主动请求。

## 场地与开局

| 项目   | 规则                                                 |
| ------ | ---------------------------------------------------- |
| 人数   | 固定 1 人                                            |
| 场地   | 固定 10 × 20（宽 10，高 20）                         |
| 时长   | 最多 1500 tick                                       |
| 方块   | I、O、T、S、Z、J、L 七种，type 1–7；形状表随发行固定 |
| 发牌   | 7-bag：每 7 块内七种各出现一次，顺序由 PRNG 洗牌     |
| 出生点 | 顶部中央 `(x, y) = (3, 0)`，rotation 0               |
| 预览   | 下一块类型对玩家可见                                 |

坐标左上为 `(0, 0)`，向右 x 增大，向下 y 增大，`index = y * width + x`。随机数使用 xorshift32，状态 `rngState` 随世界保存；种子 0 使用 `0x9e3779b9`，初始化先丢弃 4 个输出。抽牌只在 bag 不足时发生，消耗的随机数完全由世界状态决定，同一世界与动作序列重演结果相同。

## 世界与观察

世界包含 `tick`、`maxTicks`、`width`、`height`、`cells`（长度 200 的已锁定格子数组，0 为空，1–7 为方块类型）、`piece`（当前下落方块 `{ type, rotation, x, y }`）、`queue`（后续方块类型，至少 1 个）、`rngState`、`lines`、`score`、`level`、`fallCounter`（距下次重力下落已计 tick）、`over`、`playerId`。`cells` 只含已锁定格子，下落方块的格子不在其中。

观察只含公开事实：`tick`、`maxTicks`、`selfId`、`board: { width, height, cells }`、`piece`、`next`（下一块类型）、`lines`、`score`、`level`、`fallInterval` 与上一 tick 的公开事件 `events`。结束后不再产生观察。

## 动作

每 tick 登记一个动作：

- `{ type: "move", direction }`：向 `left`、`right` 移动一格，或 `down` 软降一格（不计分）。
- `{ type: "rotate", rotation }`：`cw` 顺时针或 `ccw` 逆时针旋转 90°。
- `{ type: "drop" }`：硬降到底并立即锁定，不计分。
- `{ type: "idle" }`：停留。默认动作是 `idle`。

移动或旋转与已锁定格子、边界冲突时无效（无副作用）；软降在触底时无效。旋转支持水平踢墙：依次尝试原位、左移 1、右移 1、左移 2、右移 2；O 块旋转无效果。所有动作先于重力结算。

## 结算顺序

一个 tick 内按以下顺序判定，从本 tick 开始时的世界出发，后续阶段读取前一阶段的结果：

1. **玩家动作**：按上述规则立即判定；硬降一路落底并锁定。
2. **重力**：本 tick 已硬降锁定（新块已出生）时跳过；否则 `fallCounter` 加 1，达到等级间隔时下落一格，已触底则锁定。
3. **锁定与消行**：方块并入 `cells`，满行消除、上方整体下移，按消行数计分，抽取下一块并检查 top-out。
4. `tick` 加 1；`over` 或达到 1500 tick 时结束。

## 计分、等级与终局

- 消行得分 = 消行数 × 锁定时的等级（1 行 = 1×等级，4 行同消 = 4×等级）；等级只影响速度与消行分。
- 软降、硬降不计分。
- `level = 1 + floor(lines / 10)`；重力间隔 `max(1, 12 - (level - 1))` tick。
- 新块在出生点放不下即 top-out；`tick` 达到 1500 同样结束。结束原因为 `top-out` 或 `tick-limit`，名次固定第 1，`score` 为最终得分。

## 排位与榜单

本游戏不使用 Elo。结算写入参与者 `score`，并把游戏条目的 `bestScore` 更新为历史最高；排行榜按 `bestScore` 降序（同分并列，按 userId 稳定展示）。`matchesPlayed` 计挑战次数，胜负不计。上传新代码不影响已有纪录。

## 公开事件

| 事件        | 触发                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| `spawn`     | 锁定后新方块成功出生；开局观察的 events 为空，`piece` 为类型                   |
| `move`      | 移动生效，`direction` 为方向                                                   |
| `rotate`    | 旋转生效，`rotation` 为方向                                                    |
| `hard-drop` | 硬降，`cells` 为下落格数，不计分                                               |
| `lock`      | 锁定，`piece` 为类型，`lines` 为消行数，`rows` 为被消的行号，`gain` 为消行得分 |
| `level-up`  | 升级，`level` 为新等级                                                         |
| `top-out`   | 新块放不下，本局结束                                                           |

移动/旋转被判定无效时不产生事件；软降无效同样不产生事件。

## 官方 bot

官方 bot 采用单步落点搜索：每 tick 对每个旋转与可达列模拟硬降，用聚合高度、洞数、起伏与消行数的经典权重评估落点后的堆叠，然后每 tick 一个动作（先旋转、再平移、最后硬降）走向目标落点。它使用与其他玩家完全相同的执行路径与资源限额。
