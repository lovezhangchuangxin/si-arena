## 共同约束

- 用户自行在本地使用 AI，平台不接入模型 API。
- 只做自由竞技，不做严格模型评测。
- 每个游戏独立保存最新代码、排位和比赛成绩，不设跨游戏综合积分。
- 只有玩家主动发起匹配、挑战或开启竞技场才创建比赛；离线选手可以被选为对手。
- 官方示例 bot 使用普通玩家的执行与限额路径；双人官方练习不计分，竞技场官方席位不产生计分对，单人官方 bot 供本地比较，系统账号不入榜。
- 游戏以 tick 推进，玩家代码每 tick 运行一次，动作统一结算。
- 不保存玩家历史代码；回放也不执行玩家代码。
- 玩家执行错误只使该玩家当 tick 失败，下一 tick 重新调用入口。

## 文档约定

本文索引面向产品与游戏规则；安装、测试和文档职责见 [开发指南](../development.md)。

文档中的规则、参数和接口是实现约束。玩法变更必须明确更新相应规范，不能以实现细节或玩家代码执行顺序替代规则。

更新玩法时，需要同步检查对应游戏的提示词、SDK、规则引擎和本地分发包，避免同一规则出现不同描述。
