# 魔方

## 核心玩法

魔方是独立的单人游戏 `cube`：一局只有一个打乱的三阶魔方，你要在 400 tick 内把它还原。每走一步扣 10 分，满分 2000；还原即结算，没还原不计分。排行榜按历史最高分排名，同一玩家可以随时重开刷新纪录。

本游戏没有对手、练习或 Boss 概念：玩家主动发起即开局，每次挑战独立成局，结束即结算 `bestScore`。任务仍进入 worker 队列，资源繁忙时会等待；同一用户同一游戏最多一个未完成的主动请求。

## 场地与开局

| 项目     | 规则                                                       |
| -------- | ---------------------------------------------------------- |
| 人数     | 固定 1 人                                                  |
| 魔方     | 三阶，54 个贴纸；六个面 U R F D L B，每面 9 个             |
| 时长     | 最多 400 tick                                              |
| 打乱     | 22 步，每步从 18 种转动中抽取；同面不连续、同轴不三连      |
| 信息公开 | 打乱步数公开，打乱序列与随机数状态都不公开                 |
| 计分     | `max(0, 2000 - 10 × 步数)`，只在还原时结算                 |

贴纸编号为 U 0–8、R 9–17、F 18–26、D 27–35、L 36–44、B 45–53，每块贴纸的值等于它所属的面序号。中心贴纸（`4`、`13`、`22`、`31`、`40`、`49`）永远不动，因此「六面单色」与「每个贴纸回到自己的面」等价。

打乱使用 xorshift32，种子 0 使用 `0x9e3779b9`，初始化先丢弃 4 个输出；抽取时先定面再定幂次（90°、180°、-90°）。打乱只在 `init` 内发生，世界不保存随机数状态，`step` 完全确定。

## 世界与观察

世界包含 `tick`、`maxTicks`、`facelets`（长度 54 的贴纸数组）、`moves`（已走步数）、`score`、`solved`、`playerId`。世界不保存打乱序列，回放因此不会泄露开局信息。

观察只含公开事实：`tick`、`maxTicks`、`selfId`、`facelets`、`moves`、`score`、`solved`、`scrambleLength` 与上一 tick 的公开事件 `events`。结束后不再产生观察。

## 动作

每 tick 登记一个动作：

- `{ type: "move", move }`：转动一个面。`move` 是 18 个名字之一：`U`、`U2`、`U'`、`D`、`D2`、`D'`、`L`、`L2`、`L'`、`R`、`R2`、`R'`、`F`、`F2`、`F'`、`B`、`B2`、`B'`。
- `{ type: "idle" }`：空过一 tick，不计步。默认动作是 `idle`。

转动永远合法：任何一步都会生效，把魔方转到某个状态。空过不扣分，但会消耗 tick 预算，因此「想清楚再动」是允许的，磨蹭到 400 tick 则本局零分。

## 结算顺序

1. 若本 tick 是 `move` 且魔方未还原，执行转动，`moves` 加一，产生 `turn` 事件。
2. 转动后若魔方还原，置 `solved`、写入 `score = max(0, 2000 - 10 × moves)`，产生 `solved` 事件。
3. `tick` 加 1；`solved` 或达到 400 tick 时结束。

## 计分与终局

- 还原得分 = `max(0, 2000 - 10 × 步数)`：20 步 1800 分，100 步 1000 分，200 步 0 分。
- 没还原不计分；200 步之后仍未还原的局即使后来还原也是 0 分。
- 结束原因为 `solved` 或 `tick-limit`，名次固定第 1，`score` 为最终得分。

## 排位与榜单

本游戏不使用 Elo。结算写入参与者 `score`，并把游戏条目的 `bestScore` 更新为历史最高；排行榜按 `bestScore` 降序（同分并列，按 userId 稳定展示）。`matchesPlayed` 计挑战次数，胜负不计。上传新代码不影响已有纪录。

## 公开事件

| 事件     | 触发                                                     |
| -------- | -------------------------------------------------------- |
| `turn`   | 转动生效，`move` 为转动名，`moves` 为累计步数            |
| `solved` | 还原，`moves` 为总步数，`score` 为本局得分               |

`idle` 不产生事件。

## 官方 bot

官方 bot 采用分层法：底面十字（查表得到最短解）、第一层角块（弹块 + 三种插入）、中层棱块（对齐后左/右插入）、顶层分四步（棱朝向、角朝向、角排列、棱排列，各步在少量宏动作上做广度优先搜索）。它每一步只算一个算法，把计划存进 Memory，与其他玩家走完全相同的执行路径与资源限额，平均约 138 步还原。
