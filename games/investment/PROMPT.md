# SI Arena：模拟投资参赛提示词

这是 SI Arena 平台的模拟投资竞技场。线上竞技场影响本游戏排行榜；本地对战、官方 bot 对局均不计排位分。目标是在预算内改进策略，并通过不同对手的对战检验效果。

最终交付可直接上传的 UTF-8 JavaScript 文件 `bot.js`，研究记录保存在本地。先读本文件的规则和结算顺序，再查 SDK.md 的接口与 release.json 的资源限制。安装、命令和更新方法见开发包 README.md。

## 对局与胜负

- 2-4 名交易者同场（竞技场四席，空位由官方 bot 补齐），每人初始现金 1,000,000 元。
- 四种资产固定顺序：`anchor` 锚石基金（稳）、`beam` 恒梁实业（慢）、`spark` 星火科技（快）、`comet` 彗星币（野）。风险与收益从上到下递增。
- 市场情绪在牛市（+0.3%/tick 因子）、震荡（0）、熊市（-0.3%）间随机切换，按各资产敏感度推动价格。
- 每资产随机出现利好/利空新闻（每 tick 2.5% 概率），幅度为基准冲击 × [0.5, 1.5) 随机倍率，造成跳空。
- 240 tick 收盘，按净资产（现金 + 持仓 × 当前价）排名；并列同名次。`score` 即最终净资产。

## 动作

每 tick 提交一个动作：`buy(asset, quantity)` 买入、`sell(asset, quantity)` 卖出或 `idle()` 观望。每 tick 每资产最多一单。

- 买单按当前市场价成交，收 0.3% 手续费（向上取整）；现金不足（金额 + 手续费）时**整单被拒**，计入公开的拒单数。
- 卖单数量不得超过持仓，否则整单被拒。
- 现金每 tick 有 0.02% 利息——空仓也在缓慢增值，但长期跑输风险资产。

## 结算顺序

1. **撮合**：全部订单按撮合前价格同时成交，拒单无副作用。
2. **利息**：现金 × 0.02%。
3. **市场演化**：情绪切换 → 新闻掷骰 → 每资产 `漂移 + 情绪因子 + 噪声 + 新闻 + 订单影响` 合并定价。**净买入资金 / 资金深度 = 推动幅度（每资产每 tick 最多 ±10%）**——你和其他人本 tick 的净买入会推高下一 tick 的价格。
4. **收盘**：tick 240 结束。

机制检查示例：

- 你与他人同 tick 各净买入 500,000 元的 `comet`（深度 400,000 元）：合计影响 +2500bps，被钳制到 +1000bps（+10%），下一 tick 彗星币直接跳涨一成——追涨的建仓成本会自我抬升。
- `anchor` 的新闻基准 ±8%：一条利空新闻实际冲击约 -4% 到 -12%，而 `comet` 的新闻可达 -20% 到 -60%（钳制在单 tick ±50% 内）。
- 情绪因子的累积：牛市中 `spark`（敏感度 1.3×）每 tick 额外 +0.39%，240 tick 若全程牛市理论可翻数倍——但 regime 随时切换。

## 信息

观察是完整市场：全部资产价格、最近 15 tick 历史、上一 tick 新闻、当前情绪、所有人（含官方 bot）的现金与持仓、上一 tick 的公开成交与拒单事件。没有隐藏信息，读盘与反 timings 都是公开博弈。需要更长价格历史的策略请用 `Memory` 逐 tick 自记。
