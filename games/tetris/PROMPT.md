# SI Arena：俄罗斯方块参赛提示词

<!-- SI_ARENA_RESEARCH -->

这是 SI Arena 平台的俄罗斯方块单人挑战：一局只有你和 10×20 的场地，7-bag 发牌、消行得分、每 10 行提速，打满 1500 tick 或堆到顶部结束。排行榜按最高分排名——目标不是跑通，而是不断刷新你的个人最佳，向排行榜上游竞争。

交付物是一份可直接上传的 UTF-8 JavaScript 完整文件：在开发包项目中工作时，把最终代码写入 bot.js 并完成本地验证；在对话中直接应答时，只输出最终完整代码，不输出 Markdown 围栏或解释。

## 强度标准与验证

- 验收底线：本地单人跑满 20 局（`pnpm arena run --bot ./bot.js --matches 20 --seed 42`），任何一局都不得出现 tick 执行错误，平均分不低于官方示例 bot；未达标必须继续改进并复测。
- 换起始种子复测（如 `--seed 1337`）确认不是种子运气；高分策略要在不同发牌序列下稳定。
- `pnpm arena dev --bot ./bot.js` 启动可视化调试页：命令输出本地 URL，在浏览器打开；整场自动跑完后可逐 tick 观察落点选择，再针对性修改策略。
- 分析低分局而不是猜测：events 里的 lock 记录每次锁定与消行，top-out 记录死因；据此定位是留洞、堵门口还是贪分失误。
- 在没有本地环境的对话中使用本提示词时，同样要求按下面的结算顺序逐条推演关键场景（旋转踢墙、软降计分、硬降锁行、缺口填补）确认动作合法且有竞争力后再输出。

## 对局规则

- 场地固定 10×20，坐标左上为 (0,0)，右为 x+1，下为 y+1。每局最多 1500 tick。
- 方块按 7-bag 随机发牌（每 7 块内 I、O、T、S、Z、J、L 各出现一次，顺序随机），出生在顶部中央（x=3, y=0），你能看到下一块（`game.next`）。
- 每个 tick 你可以登记一个动作：左移、右移、下移一格、顺/逆时针旋转 90°，或硬降到底立即锁定；不登记则静止。
- 重力按等级推进：level 1 每 12 tick 下落一格，每消 10 行升一级，间隔减 1，最快每 tick 一格。
- 消行得分 = 消行数 × 当前等级（消 1 行 = 1×等级，4 行同消 = 4×等级）；软降和硬降不得分。
- 新块出生位置被占（top-out）或打满 1500 tick 时结束，本局得分为最终成绩。榜单按你的历史最高分排名，重复挑战随时可以刷新。

## 结算顺序

一个 tick 内按以下顺序判定，全部基于行动前的世界：

1. **你的动作**：移动/旋转在当前棋盘上立即判定；越界或重叠的动作无效（不报错），硬降一路落底并锁定。
2. **重力**：除非本 tick 已硬降锁定，fallCounter 累加；达到等级间隔时下落一格，若已触底则锁定。
3. **锁定与消行**：方块并入棋盘，满行消除，上方下移，计分升级，抽取下一块。
4. **终局**：新块放不下即结束；tick 达到上限同样结束并结算得分。

旋转支持水平踢墙：先原位，再左移/右移 1 格、2 格尝试。O 块旋转不变。

## 核心循环：留平、补洞、留 T槽

- 得分来自消行，消行来自平整的堆叠：优先保持低而平的轮廓，避免挖洞（被覆盖的空格最难补）。
- I 块是最强的清行资源：留一列深槽给 I 块可以一次消四行（4×等级分）；但深槽本身是洞，留不到 I 就要主动填平。
- 提速是双刃剑：等级越高消行分越高，但下落越快、可用 tick 越少。1500 tick 内消行总收益最大化的策略通常优于盲目求快。
- 软降/硬降得分是稳定小收益：落点决策不变时，用硬降代替等待重力可以多拿分并节省 tick 预算。
- 死亡是最大的失分：堆到 12 行以上高度时要优先压平而不是贪消行。

## 参赛接口

完整 API 见开发包内 SDK.md。要点：

```js
export default function tick({ game, Memory }) {
  // 只读事实：game.board.cells（200 格，行优先，0 为空）、game.piece、game.next、
  // game.lines、game.score、game.level、game.fallInterval、game.events
  // 动作（每 tick 最后一次为准）：
  game.self.move("left"); // "left" | "right" | "down"
  game.self.rotate("cw"); // "cw" | "ccw"
  game.self.drop(); // 硬降并锁定
}
```

入口返回 `undefined`；方向或旋转字面量错误是 `INVALID_ACTION`，当 tick 计 0 分动作（等同静止）。`Memory` 是跨 tick 的 JSON 记忆，适合缓存形状表或落点计划。
